Hướng dẫn nhanh (Client)

  1. Tải file installer cho Windows và chạy: VirtuSetup.exe
  2. Kiểm tra SHA256: tải file CHECKSUMS.txt và so sánh với tập tin vừa tải.
  3. Cài đặt Python 3.9+ cho các máy chạy client nếu cần.
  4. Nếu dùng mã nguồn: python -m pip install -r requirements.txt --break-system-packages
  5. Khởi động client: python main.py
