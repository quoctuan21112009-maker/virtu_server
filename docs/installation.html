Hướng dẫn nhanh (Client)

  1. Tải file installer cho Windows và chạy: VirtuSetup.exe
  2. Cài đặt Python 3.9+ cho các máy chạy client nếu cần.
  3. Nếu dùng mã nguồn: python -m pip install -r requirements.txt --break-system-packages
  4. Khởi động client: python main.py
